# How to Use `build_inference_from_logs.py`

This script processes log files to generate inference outputs for the Water Allocation Challenge.

## Usage
1. Navigate to the project directory:
   ```bash
   cd /home/danie/thesis_experiment/Alympics
   ```
2. Run the script:
   ```bash
   python3 temp/build_inference_from_logs.py
   ```
3. Check the output directory for the generated inference files.

## Function
- Processes simulation logs.
- Outputs structured inference data for analysis.
