[2] 你目前「實際在用」的主流程（唯一重點）
你目前真正常用流程是：run_all_permutations.py

實際執行邏輯：
1) 設定 slice（例如 1~120）
2) 指定 opponent-info-mode
3) 對每個 permutation 建立 backend_config（5 位 agent 對 5 個模型的一種排列）
4) 呼叫 run.py.run_experiment(...) 跑完整 meta-round
5) 每個 experiment 完成後自動輸出 inference（每 agent 的 cot.json + code.py）
6) 最後輸出 global_batch_report.json
